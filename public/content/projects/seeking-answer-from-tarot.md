*What am I seeking when asking a machine?*

This is a React web app that offers Tarot divination across three spread types (i.e., Past-Present-Future, Relationship, and Life Purpose). Users can draw cards, receive personalised interpretations, and revisit past readings through a history view. This is done in a group project of four, where I was responsible for DashView and HistoryView, the API requests for three types of reading, component state management as well as reviewing and maintaining the (persistence-)model-view-presenter architecture.
